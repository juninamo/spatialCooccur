This vignette walks through the disease- / condition-group comparison workflow in spatialCooccur. The pattern is:

  1. Collect per-sample spatial transcriptomics data (one image per sample, or multiple images grouped by patient).
  2. Compute a spatial co-occurrence score per sample with one of the *_per_sample() helpers.
  3. Test for differences between groups (e.g. disease vs. control) with compare_groups().
  4. Visualize with plot_group_delta_heatmap(), plot_pair_boxplot(), or plot_volcano_groups().

Simulate a two-group dataset

generate_sim_groups() wraps generate_sim() to produce n_samples_per_group samples per condition, each with a possibly noised close_ratio around the group baseline. Here we use test_type = "distribute" so that planted co-localization is at the spatial scale the local neighborhood graph is sensitive to.

set.seed(1)
df_groups <- generate_sim_groups(
  n_samples_per_group = 4,
  group_close_ratio = list(disease = 0.85, control = 0.15),
  n_types = 5,
  n_cells = 400,
  test_type = "distribute",
  distance_param = 15,
  between_sample_noise = 0.03,
  seed = 1
)

df_groups is a long-format data.frame with columns x, y, cell_type, sample_id, group, patient. The same shape is what the *_per_sample() helpers accept directly; for Seurat input they read the equivalent fields from meta.data and @images.

Group comparison

compare_groups() runs a per-cluster-pair test between two groups. Set ref_group to make the sign of effect interpretable (effect = mean(test) - mean(reference)).

cmp_wilcox <- compare_groups(
  per_sample,
  value     = "zscore",
  method    = "wilcox",
  adjust    = "BH",
  ref_group = "control"
)

Patient-level aggregation

If you have multiple images per patient and want one observation per patient, pass unit = "patient" to the *_per_sample() helpers. Each image-level result is then averaged within patient before group comparison:

per_patient <- nhood_enrichment_per_sample(
  df_groups, sample_key = "sample_id", group_key = "group",
  cluster_key = "cell_type", patient_key = "patient",
  unit = "patient",
  neighbors.k = 15, n_perms = 100, n_jobs = 1
)

Inputs other than a data.frame

All *_per_sample() helpers accept three kinds of input:

  • A Seurat object with multiple images. sample_key is a column of meta.data whose values match names(obj@images).
  • A list of Seurat objects, where each may itself have multiple images. source_index in build_sample_design() records the list origin.
  • A data.frame with x, y, the cluster column, and the sample / group / (optional) patient columns.

build_sample_design() is the small helper that turns any of these into the design table used downstream — call it directly if you only want the sample / group / patient mapping.

build_sample_design(
  df_groups,
  sample_key  = "sample_id",
  group_key   = "group",
  patient_key = "patient"
)
